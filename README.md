Hi, I'm a student with a love for building small tools, tinkering with hardware, and
messing around with code just to see what happens. Right now I mostly write Python —
small GUI programs and random experiments — and I'm building up my web dev skills
with HTML, CSS and JavaScript, with frameworks like React next on the list. On the
hardware side I work with Arduino (C++), ESP32, and Raspberry Pi Pico (MicroPython).
I also had some past experience with game development, though it's not something
I'm actively doing these days.
